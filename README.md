## Overview

This repository contains lab work for LAB 3 of the Computer Fundamentals & Career Pathways (CSE103) course at K.R. Mangalam University, Gurugram.

The purpose of this lab is to understand Git, GitHub collaboration, version control, Markdown documentation, and API interaction.

Clone the repository:

```bash

```

Navigate into the project:

```bash
cd cse103-lab-LAB3
```

Run the Python file:

```bash
python3 main.py
```
